Changelog:
Easy Elevators
https://curseforge.com/minecraft/mc-mods/easy-elevators

=========
v1.5: The 'elevatorBlocks' and 'elevatorChains' lists can now be picked from a list in the in-game config.
Config changes made in-game now apply right away, without a restart.

=========
v1.4: Changed the mod's Java package to com.serilum.*.
Updated mod information in the mods.toml and fabric.mod.json files.
No functional changes.

=========
v1.3: (Forge & Neo) Removed redundant event register annotations.
- This fixes events loading when they shouldn't.

=========
v1.2: (Fabric) Fixed a mixin conflict during load.

=========
v1.1: Added Bundle support. The mod can now be enabled/disabled via bundle configs.
(NeoForge) Fixed the in-game config screen not working correctly.

=========
v1.0: Initial release of Easy Elevators.
