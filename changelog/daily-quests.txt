Changelog:
Daily Quests
https://curseforge.com/minecraft/mc-mods/daily-quests

=========
v4.0: Fixed dedicated NeoForge and Forge servers crashing on startup.
Fixed a crash each morning when only a few quest types are enabled.
Fixed a crash when generating Tame Animal quests with some modded mobs.
Fixed players being stuck on the introduction screen after relogging or a server restart.
Fixed the /dq debug generate command not ending the introduction screen.
Fixed quests not refreshing for players outside the Overworld, or when the time skipped past the refresh time.
Fixed quest reward items losing what the loot table set on them, like lore, custom names and enchantments.
Fixed shift-clicked furnace output not counting for Smelt Item quests.
Fixed quest names and the introduction always showing in English on servers; they now use the player's own language.
Fixed the /dq info, /dq quests and quest summary headers showing as raw text for players without Collective.
Removed the 'introductionQuestScreenTitles' and 'introductionQuestScreenDescriptions' config options, as the introduction text is now translated.
(26.2+) Added the Block Arrow quest type back.
(26.2+) Fixed Collect Honey quests not counting filled honey bottles.

=========
v3.1: Changed the mod's Java package to com.serilum.*.
Updated mod information in the mods.toml and fabric.mod.json files.
No functional changes.

=========
v3.0: Changed the mod's keybinding code to use InputConstants.

=========
v2.9: Fixed an incorrect mixin reference.

=========
v2.8: Updated the mod's text to use Collective's new translation system, which adds many languages alongside English!
For more information see https://serilum.com/translations.

=========
v2.7: (26.1.2 NeoForge) Updated to work with NeoForge version 26.1.2.21-beta and above.

=========
v2.6: (26.1) Moved the tick event to Post.
[NeoForge] Fixed sheep mixin target.

=========
v2.5: (1.21.9 Forge) Fixed incorrect remnant files included in the mod jar.

=========
v2.4: Updated mod to use Collective's new RegisterKeyMappingsHelper.

=========
v2.3: (1.21.5) Fixed incorrect mixin references.

=========
v2.2: Improved logic when the GUI elements should be hidden.

=========
v2.1: Fixed a crash on load due to a mod incompatibility.
Fixed a rare client crash after generating new quests.

=========
v2.0: Changed packet fields to be non-static to prevent bugs in queued packets.

=========
v1.9: (Forge & Neo) Removed redundant event register annotations.
- This fixes events loading when they shouldn't.

=========
v1.8: Fixed a crash when loading a specific world on Forge.

=========
v1.7: Added the 'disableGUIQuestListEntirely' config option.
Added the /dq quests command.

=========
v1.6: Added a daily quests introduction screen for the first in-game day.
This screen is located inside the quest list, and contains information.
The function can be disabled entirely or the content changed via the config.

=========
v1.5: Fixed quests not immediately generating in a new world.
Fixed the UseItem Shield quest not progressing.
Fixed some potion quests not progressing correctly.

=========
v1.4: Added support for automatic lowering of the quest list with the BedrockIfy save icon.
Can be disabled in the config.

=========
v1.3: Lowered the default quest generation time to daytime=20 ticks.
Fixed SlayMob not progressing correctly.
Made some tweaks to quest targets.

v1.1: Added the /dq info command.
